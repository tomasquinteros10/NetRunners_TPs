\subsection*{20.1 ¿Qué elementos de direccionamiento son necesarios para identificar al usuario TS destino?}

Para identificar al usuario TS destino se necesita:

\begin{enumerate}
    \item Identificación del usuario.
    \item Identificación de la entidad de transporte.
    \item Dirección de la estación.
    \item Número de la red.
\end{enumerate}

\subsection*{20.2 ¿Cuáles son las cuatro estrategias que puede utilizar un usuario TS emisor para encontrar la dirección de otro usuario TS?}

\begin{enumerate}
    \item El usuario TS emisor ya conoce la dirección del usuario destino.
    
  \item Utilizar direcciones conocidas para servicios comunes.
    
  \item Utilizar un servidor de nombres para obtener la dirección correspondiente al usuario destino.
    
  \item Crear el proceso destino cuando se realiza la solicitud, obteniendo su dirección durante este proceso.
\end{enumerate}
